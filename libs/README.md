# libs

## 目录职责

`libs/` 保存预编译库和历史库说明，是链接期问题和库交付问题的入口目录。

## 什么时候从这里进入

- 需要排查链接错误、缺符号或库版本问题。
- 需要确认某个能力来自源码编译还是预编译库。
- 需要查看历史库裁剪说明。

## 当前内容

- `libandes.a`：Andes 相关预编译库
- `libstdc++.a`：C++ 标准库
- `readme.txt`：历史库裁剪和变更记录

## 与构建/配置的关系

- 这里主要存放二进制库，不是源码实现目录。
- 遇到链接问题时，建议先确认：
  1. 板级 `defconfig` 是否启用了对应能力。
  2. 头文件和库是否匹配。
  3. 问题应落在 `libs/` 还是源码目录。

## 推荐下一步

- 架构相关问题：看 `../arch/README.md`
- 历史裁剪信息：看 `readme.txt`
