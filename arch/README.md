# arch

## 目录职责

`arch/` 保存 CPU 架构相关实现，是更底层的平台适配入口。

## 什么时候从这里进入

- 需要排查与 CPU 架构、编译器、启动底层细节直接相关的问题。
- 需要确认某个实现到底属于架构层、板级层还是 OS 层。

## 关键内容

- `andes/`：当前可见的架构目录

## 与构建/配置的关系

- 根 `Makefile` 会根据 `CONFIG_CPU_ARCH` 选择 `arch/<arch>/`。
- 一般业务和公共组件问题不会直接从这里进入，只有确定是架构层问题时才建议深入。
