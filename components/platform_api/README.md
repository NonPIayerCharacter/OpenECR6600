# components/platform_api

## 目录职责

`components/platform_api/` 提供平台信息、系统配置和格式转换相关的公共接口，是“平台识别/系统配置”类问题的入口。

## 什么时候从这里进入

- 需要看平台列表、产品类型、系统配置读取。
- 需要排查平台枚举、配置项映射或格式转换问题。
- 需要判断应用层读取的系统参数来自哪里。

## 关键文件

- `system_config.c`：系统配置相关实现
- `platform_list.c`：平台列表与平台识别
- `format_conversion.c`：格式转换相关实现
- `Make.defs`：组件编译入口

## 与构建/配置的关系

- 这里属于公共组件层，不应混入具体板型差异。
- 如果配置项与具体产品强绑定，通常还需要回看板级目录或 NV 配置路径。
